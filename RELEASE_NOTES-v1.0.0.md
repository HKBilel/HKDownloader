# HKDownloader v1.0.0 — Windows x64

HKDownloader is a **completely free**, multilingual desktop downloader by HKCorp.

**Highlights**
- MP4 video, MP3 audio and playlist downloads where supported by yt-dlp.
- Best quality by default, with no 8K-only dropdown or paid features.
- Optional browser-session access when authorised by the account owner.
- Monochrome Desktop Acrylic-inspired interface, nine languages, light/dark themes.
- Optional Patreon donation button (no login or premium entitlement required).

**Install**: Download `HKDownloader-Windows-x64-v1.0.0.zip`, extract it to a writable folder and run `HKDownloader.exe`. Windows 10/11 x64, .NET Framework 4.8 and internet access are required. On first use, allow the app to obtain its tools.

**Verify**: the release provides `HKDownloader.exe.sha256` and `HKDownloader-Windows-x64-v1.0.0.zip.sha256`.

**Limitations**: quality, formats, site availability and watermark-free sources depend on the site and yt-dlp. Downloads of members-only material require existing permission. A persistent download history, download queue and simultaneous different-video downloads are not included in v1.0.0.
