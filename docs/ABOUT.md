## Who is behind HKDownloader?

I'm **HKBilel**, the independent developer of **HKDownloader**. I publish the application under the **HKCorp** project name. HKCorp is a project name; it does not imply a registered company or trademark.

## Why I created it

The idea behind HKDownloader is simple: make video and audio downloads accessible through a Windows desktop application instead of requiring command-line instructions. I care about a clear interface, understandable download options, and keeping the application available to everyone.

## How it works

HKDownloader uses independent external tools—**yt-dlp**, **FFmpeg**, and **Deno**—to perform supported download and processing tasks. HKDownloader adds a graphical interface, selectable quality, download controls, tool management, light and dark themes, and nine interface languages. Site availability and download capabilities depend on each provider and yt-dlp.

## Free and independent

**HKDownloader is 100% free.** There is no subscription, premium tier, or mandatory Patreon membership. If you want to support further independent development, [Patreon](https://www.patreon.com/cw/HKBilel/membership) is entirely optional and does not unlock any features.

The application's source code remains private. The [public repository](https://github.com/HKBilel/HKDownloader) contains documentation and links to compiled releases. Rights to original project materials are reserved only where those rights are held by the developer; third-party tools have their own licences.

## Current status

The first stable release is **v1.0.0**, for Windows 10/11 x64. A persistent download history, multi-item queue, and simultaneous downloads of different videos are **not included** in this version. Changes will be announced through [official GitHub releases](https://github.com/HKBilel/HKDownloader/releases).
