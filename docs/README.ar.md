# HKDownloader v1.0.0 — العربية

## المتطلبات
Windows 10/11 بنظام 64 بت و.NET Framework 4.8 واتصال بالإنترنت. نزّل `HKDownloader.exe` من GitHub Releases. للبناء من الشيفرة على Windows، شغّل `Build-HKDownloader.cmd`.

## الميزات
- خانة واحدة للصق الروابط مع اكتشاف المنصة تلقائيًا وتغيير ألوان الواجهة وشعارها.
- يدعم YouTube وTwitch وKick وInstagram وTikTok وFacebook ومواقع أخرى متوافقة مع yt-dlp.
- فيديو MP4 بحد أقصى 720p أو 1080p أو 1440p أو 2160p (4K)، وصوت MP3 بجودة 128 أو 192 أو 256 أو 320 kbps. تعتمد الجودة الفعلية على المصدر.
- تنزيل قوائم التشغيل المدعومة، واختيار المجلد، وعرض التقدم، والإلغاء، والسجلات.
- TikTok وInstagram: تفضيل المصدر بلا علامة مائية إن توفر، وإمكانية إنشاء نسخة MP4 أخرى بعد حذف آخر 1 أو 2 أو 3 أو 5 ثوانٍ مع إبقاء الأصل. لا يضمن حذف العلامات المدمجة أو اكتشاف شاشة النهاية تلقائيًا.
- تسع لغات للواجهة، مع المظهر التلقائي أو الفاتح أو الداكن.

## الاستخدام
الصق رابطًا مدعومًا واختر MP4 أو MP3 والجودة ومجلد الحفظ، ثم ابدأ التنزيل. تُنزّل أدوات yt-dlp وFFmpeg وDeno عند الحاجة.

## الأمان
يتم التحقق من سلامة تنزيل الأدوات وبصماتها المحلية، لكن البصمة المحلية ليست توقيعًا رقميًا. لا يستورد التطبيق كلمات المرور أو ملفات تعريف الارتباط من المتصفح. نزّل فقط المحتوى المصرح لك بحفظه. راجع [الأمان](SECURITY.md).
