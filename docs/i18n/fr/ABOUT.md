# À propos de moi et de HKDownloader

[← Retour au README](README.md) · [Voir la version](https://github.com/HKBilel/HKDownloader/releases/tag/v1.0.0) · [Support me](https://www.patreon.com/cw/HKBilel/membership)

## Développeur

Je suis **HKBilel**, le développeur indépendant de **HKDownloader**. Je publie ce projet sous le nom **HKCorp** : il s'agit d'un nom de projet, pas de l'affirmation qu'une entreprise ou une marque est enregistrée.

## Objectif

HKDownloader part d'une idée simple : proposer une application Windows pour télécharger de la vidéo et de l'audio sans devoir utiliser une ligne de commande. Je souhaite offrir une interface lisible, des options compréhensibles et un logiciel accessible.

## Fonctionnement

L'application repose sur des outils tiers indépendants : **yt-dlp**, **FFmpeg** et **Deno**. HKDownloader y ajoute une interface graphique, des options de qualité, des contrôles de téléchargement, la gestion des outils, deux thèmes et neuf langues. Les contenus disponibles dépendent des plateformes prises en charge et de leurs règles.

## Gratuit et indépendant

Je maintiens HKDownloader **gratuit**, sans abonnement ni version premium. Patreon permet de soutenir le projet de façon entièrement facultative. Le code source de l'application reste privé ; ce dépôt public contient la documentation et les versions compilées.

## État du projet

La version stable actuelle est **v1.0.0**. L'historique persistant, les files d'attente et les téléchargements simultanés de vidéos différentes ne sont pas encore inclus. Les évolutions seront annoncées dans les versions officielles sur GitHub.
