## 開発者

私は **HKBilel**、**HKDownloader** の個人開発者です。**HKCorp** というプロジェクト名で公開していますが、会社や商標の登録を意味するものではありません。

## 開発の目的

HKDownloader の目的はシンプルです。Windows でターミナルのコマンドを使わずに動画や音声をダウンロードできるようにすること。見やすい画面、分かりやすい選択肢、気軽に使えるアプリを目指しています。

## 仕組み

このアプリは外部の独立したツール **yt-dlp**、**FFmpeg**、**Deno** を利用しています。HKDownloader はその上に GUI、画質設定、ダウンロード操作、ツール管理、2 種類のテーマ、9 言語表示を提供します。ダウンロード可否は対応サイトとその規則に依存します。

## 無料・個人開発

HKDownloader は**無料**で公開し、プレミアムプランや定期購入を設けていません。Patreon の支援は完全に任意です。アプリのソースコードは非公開で、この公開リポジトリには文書とビルド済みの配布物を置いています。

## 現在の状況

現在の安定版は **v1.0.0** です。永続的な履歴、ダウンロードキュー、異なる動画の同時ダウンロードにはまだ対応していません。今後の更新は GitHub の公式リリースでお知らせします。
