## المميزات

- **الفيديو والصوت:** تنزيل MP4 وMP3 وقوائم التشغيل عندما يسمح الموقع وyt-dlp بذلك.
- **الجودة:** أفضل جودة متاحة افتراضيًا، وخيارات 720p و1080p و1440p و4K عند توفرها.
- **المواقع:** المواقع المدعومة من yt-dlp مثل YouTube وTwitch وInstagram وTikTok، وفق قيود كل منصة.
- **الواجهة:** تصميم شبه شفاف مستوحى من Windows Acrylic مع وضعين فاتح وداكن.
- **اللغات:** الإنجليزية والإسبانية والفرنسية والألمانية والبرتغالية والإيطالية والعربية واليابانية والصينية، مع دعم اتجاه اليمين إلى اليسار للعربية.
- **التحكم:** اختيار مجلد الحفظ وعرض التقدم والإلغاء وقصّ نهاية المقطع يدويًا بشكل اختياري.
- **الأدوات:** تثبيت yt-dlp وFFmpeg وDeno والتحقق من تحديثاتها.
- **جلسة المتصفح:** وصول اختياري بموافقتك إلى المحتوى المسموح لك بالوصول إليه؛ لا يتجاوز الاشتراكات أو قيود الدخول.

<a id="installation"></a>
## التنزيل والتثبيت

1. نزّل ملف ZIP الرسمي لنظام Windows x64.
2. فك الضغط في مجلد لديك إذن الكتابة فيه.
3. شغّل `HKDownloader.exe`.
4. عند التشغيل الأول، ثبّت الأدوات المقترحة (yt-dlp وFFmpeg وDeno) أو أجّل التثبيت.
5. الصق رابطًا مدعومًا، واختر الإعدادات، ثم ابدأ التنزيل.

**المتطلبات:** Windows 10 أو 11 بنظام 64 بت، و.NET Framework 4.8، واتصال بالإنترنت.

> نزّل ملف ZIP الخاص بالتطبيق، وليس ملفات «Source code» التي ينشئها GitHub تلقائيًا؛ فهي تحتوي على الوثائق العامة فقط، ولا تتضمن التطبيق أو شيفرته المصدرية الخاصة.

<a id="privacy"></a>
## الخصوصية والاستخدام المسؤول

لا تحتاج إلى حساب HKDownloader. استخدام جلسات المتصفح اختياري ويتطلب موافقتك. قد يقرأ yt-dlp ملفات تعريف الارتباط المحلية ويرسلها إلى الموقع المعني عند تنفيذ طلبات مصرح بها. لا تنشر سجلات تتضمن بيانات خاصة، ولا تنزّل إلا المحتوى الذي يُسمح لك بتنزيله.

## قيود الإصدار v1.0.0

تعتمد المواقع والصيغ المتاحة على كل منصة وعلى yt-dlp. لا يتضمن هذا الإصدار **سجل تنزيلات دائمًا أو قائمة انتظار لعدة تنزيلات أو تنزيل فيديوهات مختلفة في الوقت نفسه**. تدعم بعض الصيغ حتى أربعة أجزاء متوازية؛ وهذا لا يعني تنزيل عدة فيديوهات معًا.
