# Acerca de mí y de HKDownloader

## Quién está detrás

Soy **HKBilel**, el desarrollador independiente de **HKDownloader**. Publico este proyecto bajo el nombre **HKCorp**, que es un nombre de proyecto y no una declaración de que exista una empresa o marca registrada.

## Qué busca el proyecto

HKDownloader nace con una idea sencilla: ofrecer una aplicación de escritorio para Windows que permita descargar vídeo y audio sin depender de comandos de terminal. Me importa que la interfaz sea clara, que las opciones de descarga se entiendan y que la aplicación se mantenga accesible.

## Cómo funciona

La aplicación utiliza **yt-dlp**, **FFmpeg** y **Deno** como herramientas externas independientes. HKDownloader añade una interfaz gráfica, opciones de calidad, controles de descarga, administración de herramientas, temas claro y oscuro y nueve idiomas. La disponibilidad de descargas depende de los sitios compatibles y de sus reglas.

## Gratuito e independiente

Mantengo HKDownloader **gratuito**, sin niveles premium ni suscripciones. Patreon es una forma completamente opcional de apoyar el trabajo. El código fuente de la aplicación permanece privado; este repositorio público ofrece documentación y versiones compiladas.

## Estado del proyecto

Actualmente la versión estable es **v1.0.0**. Todavía no tiene historial persistente, colas de descarga ni descargas simultáneas de vídeos diferentes. Las mejoras futuras se anunciarán mediante las publicaciones oficiales de GitHub.
