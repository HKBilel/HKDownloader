<a id="features"></a>
## 主要功能

- **视频和音频：** 在来源网站及 yt-dlp 支持的情况下，下载 MP4、MP3 和播放列表。
- **画质：** 默认选择可用的最佳画质；条件允许时可选 720p、1080p、1440p 和 4K。
- **网站支持：** 支持 yt-dlp 兼容的网站，包括 YouTube、Twitch、Instagram 和 TikTok，具体受平台限制。
- **界面：** 灵感来自 Windows Acrylic 的半透明外观，支持浅色和深色主题。
- **语言：** 英语、西班牙语、法语、德语、葡萄牙语、意大利语、阿拉伯语、日语和中文；阿拉伯语支持从右到左布局。
- **下载控制：** 保存目录、进度显示、取消，以及可选的手动片尾裁剪。
- **工具管理：** 安装 yt-dlp、FFmpeg 和 Deno，并检查更新。
- **浏览器会话：** 在获得许可后，可选地使用已授权的浏览器会话；不会绕过付费订阅或访问控制。

<a id="installation"></a>
## 下载与安装

1. 下载适用于 Windows x64 的官方 ZIP 压缩包。
2. 将 ZIP 解压至拥有写入权限的文件夹。
3. 运行 `HKDownloader.exe`。
4. 首次启动时安装建议的工具（yt-dlp、FFmpeg 和 Deno），或选择稍后安装。
5. 粘贴兼容的网址，设置选项并开始下载。

**系统要求：** Windows 10 或 11（64 位）、.NET Framework 4.8 和互联网连接。

> 请下载应用程序 ZIP，而不是 GitHub 自动生成的“Source code”压缩包。后者只包含公开文档，不包含应用本体或其私有源代码。

<a id="privacy"></a>
## 隐私及合理使用

使用 HKDownloader 不需要账号。使用浏览器会话是可选功能，且必须获得用户许可。在授权访问时，yt-dlp 可能读取本地 Cookie 并将其发送至相应网站。不要公开包含私人信息的日志，只下载自己有权获取的内容。

[安全与隐私](../../../SECURITY.md)

<a id="limitations"></a>
## v1.0.0 的限制

可用的网站和格式取决于平台及 yt-dlp。本版本**不支持持久化下载历史、多任务队列或同时下载不同视频**。部分格式可以并行下载最多四个片段，但这不等同于同时下载多个视频。
