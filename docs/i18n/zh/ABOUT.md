## 开发者

我是 **HKBilel**，**HKDownloader** 的独立开发者。我使用 **HKCorp** 作为项目名称发布软件，但这并不意味着已注册公司或商标。

## 项目目标

HKDownloader 的想法很简单：让 Windows 用户不必输入终端命令，也能下载视频和音频。我希望界面清晰、选项易懂，让更多用户能够轻松使用。

## 工作原理

应用使用独立的第三方工具 **yt-dlp**、**FFmpeg** 和 **Deno**。HKDownloader 在此基础上提供图形界面、画质选择、下载控制、工具管理、浅色与深色主题，以及九种界面语言。实际下载能力取决于受支持的网站及其规则。

## 免费且独立

HKDownloader 保持**完全免费**，没有订阅或高级付费功能。Patreon 仅提供自愿支持独立开发的方式。应用源代码保持私有；这个公开仓库只发布文档和已编译的版本。

## 当前状态

当前稳定版本为 **v1.0.0**，尚未提供持久下载历史、下载队列和不同视频的同时下载。后续改进将通过 GitHub 官方发布页面公告。
