# HKDownloader release history

## v1.0.0 — Initial stable Windows release (pending validation)

- Free MP4/MP3 and playlist downloads, with best available quality selected by default.
- Monochrome Glassmorphism / Windows Acrylic interface, light and dark themes and nine languages.
- Optional, consent-based browser-session access (including Zen-compatible profiles where available).
- Performance tuning for compatible fragment-based formats.
- Optional Patreon support without feature gating.
- Manual ending trim and preference for clean sources where available.
- Fixes for RTL layouts, custom icons and Windows maximize behaviour.

The binary release must pass the Windows validation checklist before publication.
