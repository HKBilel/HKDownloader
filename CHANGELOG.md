# HKDownloader release history

## [v1.0.0 — First stable Windows release](https://github.com/HKBilel/HKDownloader/releases/tag/v1.0.0) — 15 November 2026

The first public stable release of HKDownloader for Windows 10/11 x64.

### Features

- Free MP4 video, MP3 audio and playlist downloads where supported by yt-dlp.
- Best available quality by default, with optional resolution choices.
- Monochrome Windows Acrylic-inspired interface, light/dark themes and nine languages.
- Optional, consent-based access to authorised browser sessions.
- Optional end trimming and attempts to prefer unwatermarked sources where available.
- Compatible fragment-based download optimisations.
- Tool installation and update management for yt-dlp, FFmpeg and Deno.
- Free use for everyone; optional Patreon donations without feature gating.

### Interface and stability refinements

- Added a first-run welcome dialog recommending installation of the download tools.
- Deferred the welcome dialog until the main window renders to avoid hidden startup windows.
- Unified spacing, typography and buttons across application dialogs.
- Balanced minimise, maximise/restore and close icons in the title bar.
- Improved compact-layout navigation, Arabic right-to-left layouts, accessibility and keyboard interactions.
- Refined progress details, classified error messages and taskbar completion notifications.

### Known limitations

- Site compatibility and available formats depend on yt-dlp and the source.
- No persistent download history, multi-item queue or concurrent downloads of different videos in this version.
